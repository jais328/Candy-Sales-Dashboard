# 🍬 Sweet Sales Intelligence - Candy Sales Dashboard

## 📊 Live Dashboard
🔗 [View Live Dashboard](https://app.powerbi.com/groups/me/reports/fa9aab87-317a-4386-8d58-121bcc6035a6/0646994c9d375e257426?experience=power-bi)

## 📌 Overview
Interactive Power BI dashboard analyzing US Candy Distributor 
sales data across factories, products, and regions.

## ✅ Features
- KPI Cards — Total Sales, Profit, Margin, Orders, vs Target
- Monthly Sales Trend Analysis
- Sales by Division (Chocolate, Other, Sugar)
- Top 5 Best Selling Products
- Geographic Sales Map (City-wise)
- Factory Performance Comparison
- Dynamic Date Slicer (2021-2024)

## 🛠️ Tools Used
- Power BI Desktop
- DAX Measures
- CSV Data Source (Maven Analytics)

## 📁 Files
- `Sweet Sales Intelligence.pbix` — Power BI file
- `Candy_Sales.csv` — Sales data
- `Candy_Products.csv` — Product data
- `Candy_Factories.csv` — Factory data
- `Candy_Targets.csv` — Target data
